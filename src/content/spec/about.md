# 关于我

你好，我是 **Katelya**。

我是一名仍在学习和成长的大学生，也是一名喜欢把想法真正做出来的长期折腾者。平时会研究 Web 项目、服务器部署、开源工具和产品设计，也会记录运动、学习与生活中那些容易被时间带走的片段。

这里不是一份完美履历，而是一座持续生长的个人数字花园。

## 我在记录什么

- **技术折腾**：开发过程中的思路、踩坑、部署和复盘。
- **项目实践**：从一个想法开始，逐渐把它变成能够真实使用的产品。
- **大学生活**：学习、活动、运动，以及成长过程中值得留下的经历。
- **日常随笔**：一些短暂的情绪、灵感和对生活的观察。

## 关于「思囿随笔」

“思囿”不是把思想困住，而是为散落的想法围出一座可以慢慢耕作的花园。

本站以蓝绿色雾境、厚涂笔触、矿物金微光和轻量 3D 空间为视觉语言。我希望它既有传统绘画的温度，也保留数字世界的秩序：远看是一幅流动的画，靠近后仍然是一处可以安静阅读的地方。
