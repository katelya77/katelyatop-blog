# Impasto Flow Garden 设计规范

日期：2026-08-04  
目标分支：`feat/impasto-flow-garden`  
目标站点：`https://blog.katelya.top/`

## 1. 目标

将当前“梵高风格静态 SVG 背景”升级为一套兼顾艺术质感、交互流畅度和文章可读性的原创数字油画系统，并彻底解决首页与文章页导航、横幅和内容区之间的层级冲突。

核心目标：

1. 从用户提供的 `van_gogh_starry_night.svg` 中提取真实笔触规律，而不是直接复制或加载整幅作品。
2. 用离线纹理生成 + 轻量 WebGL2 实现颜料厚度、法线高光、方向性笔触和昼夜光照。
3. 让首页、文章页、滚动状态、Swup 跳转和设置面板共享一套稳定几何结构。
4. 保证移动端、低性能设备、WebGL 不可用和“减少动态效果”环境都能正常使用。
5. 不影响文章、项目、个人资料、评论或内容构建流程。

## 2. 输入素材分析

用户提供的 SVG 约 26.7 MB，包含约 172,000 条独立路径笔触。路径主要由贝塞尔曲线、颜色、宽度和圆形端点组成；它没有位图、滤镜或渐变，因此适合作为以下数据的高密度样本：

- 笔触主方向；
- 曲率与转折；
- 宽度分布；
- 局部颜色分布；
- 笔触重叠密度。

它不适合直接进入浏览器，因为解析十几万条路径会提高首屏解析、布局、合成和缩放成本。

## 3. 方案选择

采用“离线结构张量/笔触场提取 + 轻量 WebGL2 厚涂渲染 + 静态降级”。

不采用：

- 直接加载 26.7 MB 原始 SVG；
- 在浏览器中实时解析全部路径；
- 引入 Three.js；
- 全站持续运行高帧率动画；
- 直接复制《星月夜》或其他名画构图。

## 4. 视觉概念

设计名：**Impasto Flow Garden / 厚涂流光花园**。

### 浅色模式

- 青绿、薄荷、湖蓝作为空气与水面；
- 鸢尾紫用于局部花朵与交互焦点；
- 奶油白用于阅读画布；
- 矿物金只用于高光、选中状态和少量星点；
- 中央文字区降低方向纹理和色彩对比，边缘增强笔触与空间层次。

### 深色模式

- 群青、钴蓝、墨青作为主体；
- 金黄星点和暖白高光形成视觉焦点；
- 柏树式暗色竖向锚点平衡横向旋涡；
- 卡片从奶油画布切换为深蓝画布，不使用纯黑。

### 材质语言

- 画布纤维：高频、低对比、静态；
- 颜料高度：来自笔触重叠与宽度；
- 法线高光：由鼠标和设备方向轻微驱动；
- 粗糙度：厚涂区域高光集中，薄涂区域更柔和；
- 空气层：低频渐变和雾化，不持续位移。

## 5. 离线资产管线

新增脚本：`tools/art/build-impasto-textures.py`。

处理流程：

1. 解析 SVG `viewBox`、路径、颜色和 `stroke-width`。
2. 将贝塞尔曲线按固定误差采样成短线段。
3. 对每段计算切线方向、曲率、宽度和颜色。
4. 在固定分辨率栅格中累计：
   - `albedo`：综合色彩；
   - `direction`：方向编码；
   - `height`：笔触厚度和重叠；
   - `roughness`：由宽度、曲率和密度推导。
5. 对高度图计算 Sobel 法线。
6. 输出网页纹理：
   - `impasto-day-albedo.webp`；
   - `impasto-night-albedo.webp`；
   - `impasto-flow.png`；
   - `impasto-normal.png`；
   - `impasto-roughness.webp`；
   - 静态降级图 `impasto-day-fallback.webp`、`impasto-night-fallback.webp`。
7. 输出 `impasto-metadata.json`，记录尺寸、版本、来源哈希和生成参数。

纹理尺寸默认 1536×864；法线与方向图可降至 1024×576。所有输出总量目标不超过 2 MB，单张不超过 600 KB。

## 6. WebGL2 渲染层

新增组件：`src/components/layout/ImpastoBackdrop.astro`。

新增脚本模块：`src/scripts/impasto-renderer.ts`。

职责：

- 创建单个全屏 `<canvas>`；
- 加载预生成纹理；
- 根据主题选择昼/夜色彩；
- 在 fragment shader 中完成：
  - albedo 采样；
  - 法线光照；
  - 粗糙度控制；
  - 极轻微方向流动；
  - 边缘暗角和中央阅读保护区；
- 只通过 `requestAnimationFrame` 更新；
- 页面不可见时暂停；
- 静止鼠标后逐步降低帧率；
- 设备像素比上限 1.5；
- 不捕获指针事件；
- WebGL 初始化失败时隐藏 canvas，显示静态背景。

默认动效必须克制：背景不能让正文产生漂移感，也不能持续大幅旋转。

## 7. 导航与页面几何

当前导航问题的根因是导航、Banner、Hero 和主内容仍存在多套位置控制。新结构固定为：

```text
body
├─ ImpastoBackdrop（固定背景，不参与布局）
├─ GalleryHeader（固定导航，独立 Overlay 层）
└─ PageShell（正常文档流）
   ├─ Hero / ArticleBanner
   └─ MainGrid
```

规则：

- `GalleryHeader` 只使用 `position: fixed`，不依赖 Banner 高度。
- 删除导航上方空白壳层和任何可改变导航 Y 坐标的首屏动画。
- 首页和文章页导航始终使用同一 `top`、高度和宽度。
- `PageShell` 使用正常文档流，不允许运行时写入 `top`。
- 首页 Hero 自身占据完整高度；文章页 Banner 自身占据文章横幅高度。
- 搜索、设置和移动菜单挂载到独立 `#overlay-root`，不参与导航网格计算。
- Swup 页面切换只更新路由状态，不重建导航几何。

桌面导航采用：

```text
品牌区（固定最小宽度） | 主导航（真正居中） | 工具区（固定最小宽度）
```

在宽度不足时逐步隐藏文字、收起搜索、最后切换移动菜单；不允许主导航与文章标题重叠。

## 8. Hero 与卡片交互

### Hero

- 保留中心标题和四个内容入口；
- 环绕卡片改为低频视差，最大旋转角不超过 2.5°；
- 不再持续监听 DOM；
- 只监听 pointer、主题、页面可见性和 Swup 路由事件；
- 移动端取消环绕卡片，仅保留静态标题和入口。

### 文章与侧栏卡片

- 采用画布纤维和轻微厚涂边缘；
- `backdrop-filter` 只用于导航和浮层，不大面积用于所有卡片；
- 悬停只改变局部高光、边框和阴影，不整体上移；
- 侧栏和正文必须保持高对比度；
- 不使用高频动画。

## 9. 性能预算

- 首屏新增 JS（压缩后）：目标小于 35 KB；
- 艺术纹理总量：目标小于 2 MB；
- 不新增大型运行时框架；
- WebGL canvas 最大 DPR：1.5；
- 后台标签页：0 FPS；
- 静止 2 秒后：降低到约 12–20 FPS；
- 鼠标交互时：最高 45 FPS；
- 手机端：默认低分辨率并关闭方向流动；
- `prefers-reduced-motion`：静态光照或完全静态。

## 10. 可访问性与降级

- Canvas 标记为 `aria-hidden="true"`；
- 所有内容和导航不依赖 canvas；
- WebGL 不可用时使用静态 WebP；
- 高对比度与打印模式关闭装饰背景；
- 主题切换后同步更新背景和浏览器 `theme-color`；
- 触控设备不要求悬停才能访问功能。

## 11. 测试与验收

新增或更新测试覆盖：

1. 导航不属于 Banner 或 Swup 容器。
2. 导航没有 Y 轴入场动画或动态 `top`。
3. 主内容不使用 `absolute + top`。
4. 页面存在唯一 `ImpastoBackdrop`。
5. WebGL 渲染器存在静态降级与可见性暂停。
6. 不加载原始 26.7 MB SVG。
7. 不新增 Three.js。
8. `prefers-reduced-motion` 和移动端降级存在。
9. 设置、搜索和菜单使用 Overlay Root。
10. Astro Check、Biome、测试和生产构建全部通过。

人工验收分辨率：

- 1920×1080；
- 1440×900；
- 1366×768；
- 1024×768；
- 390×844。

页面状态：

- 首页首次加载；
- 首页刷新；
- 首页滚动；
- 文章页首次加载；
- 首页与文章页往返；
- 浅色/深色切换；
- 设置面板、搜索和移动菜单；
- WebGL 禁用；
- 减少动态效果。

## 12. 交付方式

1. 在独立分支实现。
2. 先写回归测试并确认旧实现失败。
3. 生成并提交压缩纹理与生成脚本。
4. 完成 WebGL、导航和布局重构。
5. 运行完整 CI。
6. 创建 PR，记录性能预算与验证结果。
7. CI 全绿且无未解决评审线程后，按用户授权使用 Squash Merge 合并到 `master`。
